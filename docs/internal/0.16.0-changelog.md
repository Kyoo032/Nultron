# 0.16.0 — internal changelog

Append-only. Nothing here counts as shipped until it is staged (`host.cjs` + renderer), packed, and driven on the packaged app (`doctor --desktop`). macOS stays preview until someone opens the dmg on a Mac.

**Personal app.** This cut is the Mac/Windows installer, and the first one under the Nultron name (`Nultron Setup 0.16.0.exe`, `Nultron-0.16.0-mac-<arch>.dmg|zip`). Rizky asked for it on 2026-10-06 ("repack nultron to v0.16 then push to the public release"). It takes the next minor rather than `0.15.2` because it carries the rename, the first-run desk and the agent tools. The public release repo is `Kyoo032/Nultron`.

Version: `apps/desktop/package.json` moves `0.15.1` → `0.16.0`. Branch `chore/release-0.16.0` from `origin/main` at `de95267`. Public notes: [`docs/public/0.16.0-notes.md`](../public/0.16.0-notes.md).

## What this cut ships

Everything on `main` since the published 0.15.1 (packed from `43c1de3`) up to `de95267`. The full log is the old `unreleased.md` at `de95267`; this section is its summary, limited to what reaches the packaged Personal app. `aaf249d` ("Merge the verified-desk fixes into the 0.15.1 cut") landed after the 0.15.1 pack, so its fixes ship here for the first time.

### Desktop shell and installer (PR #135)

- **Rename to Nultron.** `productName` `Nultron` (`apps/desktop/package.json`), installer `Nultron Setup ${version}.exe` (`branding/agentforge/brand.json`), mac `Nultron-${version}-mac-${arch}.${ext}`. `appId` stays `com.tokotoken.agentforge`. Data dir `%APPDATA%\Nultron`, keychain / Credential Manager item `Nultron` / `wrap-key`.
- **No data migration (owner's call, SR-83).** A DPSBuddy user starts on a fresh desk and pastes the key again. An upgrade leaves `%APPDATA%\DPSBuddy` and `DPSBuddy/wrap-key` behind; a real uninstall removes both (`apps/desktop/build/installer.nsh`, `customUnInstall`). `killRunningApp` also ends a running `DPSBuddy.exe`.
- **Logo and icons.** Rizky's painted head in a blue tile: favicon, rail mark, splash, `icon.ico`, `icon.icns`.
- **Startup off the ffmpeg probe.** The window no longer waits on `GET /api/v1/edit/doctor`; the probe runs after load and writes `editFfmpeg` into `host-status.json`. The models.dev cache shrank from 9.1 MB to 0.4 MB.
- **`AGENTFORGE_PACKAGED=1`** in the packaged app, so the dev/test endpoint hooks are ignored (SR-85).
- **Folder picker IPC** `agentforge:pick-folder` (`apps/desktop/main.cjs:584`, `preload.cjs:59`) for the Personal folder flow below.
- **Code sandbox runtime** ships as `resources/sandbox` (`extraResources` from `vendor/sandbox-runtime`, built by `scripts/build-sandbox-runtime.mjs`, with `THIRD_PARTY_NOTICES.txt`). The installer grows accordingly; the measured size is in the pack table below.
- The updater feed was already `Kyoo032/Nultron` in 0.15.1 (`brand.json` `updates`, `build.publish`). By that feed, a 0.15.1 DPSBuddy install that checks for updates should be offered this Nultron installer once it is published (not driven).

### First run (PR #135)

- **Fresh Personal desk = Chat, Research, Images, Videos, Presentation** (`FIRST_RUN_MODES`, `packages/core/src/agents/product-modes.ts`; `firstDeskModes(isServerMode())` in `ensure-local-owner.ts`). A DPSBuddy user who moves to Nultron gets this desk too, because the data dir is new.
- **First-run guide**: five stops, Skip / close / Esc, stored in `settings.enc` (`POST /api/v1/settings/guide`), "Replay the guide" in Settings. Start over shows it again.
- The rail shows skeleton rows until the host answers, instead of flashing every mode.

### Mascot, desk and UI pass (PRs #135, #136, #138)

- The 3D Nultron mascot (`apps/web/components/nultron/`, 21 states, WebP renders) replaces the placeholder face; the desk buddy in the rail; the Chat sky and hello bubble; the pointer-following desk backdrop.
- Mode header art no longer overlaps text; contrast fixes in both themes; narrow-pane layouts; Chat composer and header laid out by container width (`chat-header.tsx`).
- Motion: smooth in a browser, **stepped in the packaged app** (`html[data-shell="desktop"]`, `apps/web/src/main.tsx`, `lib/shell-motion.ts`).
- From `aaf249d`: the Presentation / Education shape toolbar keeps the selection; Edit's Play button and timeline labels follow the desk language.

### Models (PR #135)

- One model policy table (`packages/core/src/models/model-policy.ts`); unknown ids get a conservative profile.
- Thinking self-heal: a 400/422 on the Thinking parameter retries once a level lower, remembered 30 minutes per tenant.
- New default and Recommended list for the gateway's newer models; per-mode job defaults moved.

### Mode harness and agent tools (PR #136)

- Every mode declares one harness spec (`packages/core/src/harness/modes/`); the host enforces its tools and budget. Cancel aborts the in-flight model call (Prompt enhance and the Knowledge map still ignore it).
- **Desk files**: versioned per desk, `/api/v1/files`, a Files section in the Knowledge Base, Chat file tools; Documents and Presentation can take up to 5 desk files as sources (`packages/host/src/desk-sources.ts:25`).
- **`knowledge_search`** in Chat (up to 4 excerpts).
- **`run_code`** (Python with pandas and numpy, JavaScript) in a WASM sandbox, **on by default on Personal** (`packages/host/src/code-runner/enabled.ts`: unset means `!isServerMode`). Chat and Data. 30 s per run (`code-runner/limits.ts:16`).
- **Real folder on Personal** with an approval per write or delete (`/api/v1/folder`, `apps/web/components/folder/`). Register rows SR-114, SR-115, SR-116, SR-127 (accepted / open, Low and Info).
- Data: a saved analysis keeps its provenance metadata.

### Per-mode checks (PRs #119 to #133)

Research (#119: cite-a-read-page, Comparison section), Knowledge (#120), Legal (#121: built-in positions), Documents (#122: source hold), Music (#123), Education (#124), Presentation (#125: slide count, layouts, notes), Chat turn (#126: invented source numbers dropped, attached media looked at), Images (#127: brief, poster/banner aspect), Market (#128), Meeting (#129: unsaid dates and figures), Edit (#130: five plain-sentence skills), Videos (#131: shot brief, one retry of a dead render), Data (#132: cuts), Finance (#133: claim direction). Each adds one repair round in code and no new control. #137 fixes a blank webdev page (no packaged effect; the renderer bundle-safety test is new).

### Not in this cut

Enterprise and hosted-only work merged in the same range stays out of the notes and is gated to server mode: the Phase 0 pilot, BYOK Phase A, portal invite sign-in, hosted "Add it later" and Erase account, hosted `run_code` off by default, the image's production-only install (SR-113), compose / k8s / Caddy / Tencent assets. Harness and docs (skills, maps, `tools/nultron-3d`, `packages/host/eval/**`, `scripts/ci-local.mjs`) never ship.
