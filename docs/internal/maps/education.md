## Overview

Education is a product mode (`packages/core/src/agents/product-modes.ts:18`, route `/education`). The rail mounts `EducationStudio` (`apps/web/components/work-mode-keep-alive.tsx:32`, `apps/web/src/App.tsx:364`). Opening `/education` with no `task` query shows the chooser: `education-guide-lead` and four cards (`education-guide-choices`, `apps/web/components/education-studio.tsx:376`). The presenting mascot sits above the cards through `ModeIllustration` (`education-studio.tsx:373`, `apps/web/components/mode-illustration.tsx:402`), and the chooser is the only place Education draws it. A named task is `/education?task=lesson|quiz|page|show`. An unknown value resolves to the lesson (`taskFromParam`, `apps/web/lib/education-task.ts:19`). Off `/education` the studio keeps the last task (`lastTaskRef`, `education-studio.tsx:139`) so a hidden pane does not flash the chooser.

The rail row is one card, like Finance's and Market's: `AppRail` wraps it in `rail-education-mode` (`apps/web/components/app-rail.tsx:358`) and hands the chevron to `RailItem` as its `trailing` slot (`:359-368`), so the `mode-education` link and `education-tasks-toggle` (`rail-education-tasks.tsx:32`) share one `[data-rail-row]` card (`app-rail.tsx:96-123`) and the open list renders under it (`:369`). Driven on `:3000`: the card is a child of `rail-education-mode`, holds both the link and the chevron, is 32px high at a 1000px window, and the chevron reads `tasks`, `aria-expanded="false"`, enabled. The chevron starts closed. The rows are `education-task-lesson`, `education-task-quiz`, `education-task-page`, and `education-task-show` (`apps/web/components/rail-education-tasks.tsx:42`). The visible word is `tasks` / `tugas`. More does not switch tasks. The five skills are declared in the education spec, `educationHarnessSpec` (`packages/core/src/harness/modes/education.ts:8`, skills at `:14-20`), and `MODE_HARNESSES` (`packages/core/src/harness/mode-skills.ts:43`) derives the catalog from the specs. Draft copy and the page face live in `packages/university`. Kernel tables are unchanged.

None of the four routes call the gateway (`packages/host/src/router.ts:361-364`).

## How it works

### Chooser and the rail

`useRailEducationTasks` (`rail-education-tasks.tsx:11`) is `useRailSubmenu("/education")`. The chevron only shows and hides. Each row links to `educationTaskHref` (`education-task.ts:24`). The studio reads `searchParams.get("task")` (`education-studio.tsx:136`). An empty query is the chooser (`showChooser`, `:137`). Any other value, including one the catalog does not know, is a task page, and `taskFromParam` still resolves the unknown value to `lesson`. `education-guide-change` (`:401`) links back to `/education` with no query. A task desk with nothing on it draws no mascot and no empty-desk text: the header's outcome line (`education.tasks.<task>.hint`, or `education.expectedInputs` for the lesson, `:332-336`) says what the task is, and the prompt bar below it is the only control. Show is the one task with no control to draw before a lesson exists; it draws `PresenterNeedsLesson` instead (§ Show). The More disclosure and the prompt strip around it are drawn only while they hold something (`hasMore`, `hasPromptBar`, `:340-346`): a lesson not yet created, a quiz not yet written, a page and a Show with no lesson show no empty More. The chooser's mascot is the education home pose, presenting (`MASCOT_MODE_HOME.education`, `apps/web/lib/mascot-states.ts:110`).

### Lesson deck

`POST /api/v1/education/lesson` (`packages/host/src/handlers/education.ts:24`) calls `draftLesson` with `localeForRun()`. The topic box is `education-lesson-topic` (`apps/web/components/education-studio.tsx:294`) and Create is `education-lesson-draft` (`:301`). The studio parses the outline and mounts `PresentationPreview` with `variant="simple"` (`:416-424`). That hides the permanent shape toolbar and the properties column. Add-shape buttons render into More through `toolsHost` (`:152`, the host `div` at `:596`; More is drawn once there is an outline, so the host mounts a render after the preview and the buttons appear on that second render). A selected shape shows `presentations-selection-toolbar` on the slide. Clicking a heading still edits `presentations-edit-heading`. `education-save-deck` (`:551`) posts that outline to the presentation deck store. Create moves into More once the lesson is up. The lesson draft stays in memory when the reader switches tasks, so Show can use it.

### Quiz

`POST /api/v1/education/exam` (`packages/host/src/handlers/education.ts:34-47`) calls `retrieveChunks` (`:41`) and `draftExam` (`:46`). A failure or an empty base still returns one readable item. The quiz is `?task=quiz`. Its first screen is one topic (`education-exam-topic`, `:318`) and Create (`education-exam-generate`, `:325`) in the prompt bar, and nothing under it. The page then draws `education-exam-sheet` (`:434`): numbered `education-exam-item` (`:439`), lettered `education-exam-choice` (`:448`), and `education-exam-answer` (`:458`).

### A page

A page is `?task=page`. `POST /api/v1/education/book` (`packages/host/src/handlers/education.ts:53`) reads the uploaded file with `readBookFile` (`packages/host/src/education/read-book.ts:26`). A PNG goes through `readPagePng` (`packages/university/src/education/page-face.ts:205`). A PDF uses the existing local text-layer reader. A scan the reader refuses comes back as a local empty result. The file input is `education-book-file` (`education-studio.tsx:513`), Read is `education-book-read` (`:521`), and the result is `education-book-text` (`:474`). Until a file is read the desk is only the prompt bar.

### Show

Show is `?task=show`. With a lesson and no plan yet, the only primary button is `education-presenter-build` (`:532`). Without a lesson Show has nothing to act on, so it draws `PresenterNeedsLesson` (`:110-130`, mounted at `:493` only while there is neither a plan nor a lesson): `education-presenter-needs-lesson` holds `education.presenterHint` ("Create a lesson first. Then you can show it.") and `education-presenter-create-lesson`, a primary `Link` to `educationTaskHref("lesson")` labelled `education.presenterCreateLesson` ("Create a lesson" / "Buat pelajaran"). No prompt strip and no More are drawn then (`hasPromptBar`, `hasMore`). `40c8ef1` had removed the only reader of `presenterHint` with the old empty desk, which left this task blank; it was a finding in `unreleased.md` and is fixed (2026-10-02). The other catalog hints stay unread on purpose: `education.hint` and `education.examHint` would repeat what the header's outcome line and the labelled topic field already say on the lesson and quiz desks. `POST /api/v1/education/presenter` (`packages/host/src/handlers/education.ts:67`) calls `draftPresenter`. The response carries avatar placements, subtitle cues, and `dubScript`, with `rendered` false. `PresenterStage` (`apps/web/components/education-studio.tsx:59`) draws `education-presenter-stage` (`:76`) with the avatar absolutely positioned (`education-presenter-avatar`, `:85`) and the current line (`education-presenter-cue`, `:100`). The avatar does not print its motion name or coordinates. Line picks and the spoken script (`education-presenter-dub`, `:588`) sit in More. After a plan exists, the same `education-presenter-build` testid is the quiet button inside More (`:564`). The stage bar and avatar use `--mode`. No video file is written.
