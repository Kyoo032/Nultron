# Edit

Edit is the CapCut-style timeline with an agent panel (`/edit`, rail `agent-edit`). Human and agent share one ops log; every agent change is a card with Keep / Undo / Tweak. Without ffmpeg the studio shows `edit-needs-ffmpeg`. Without a gateway key the agent panel is stub (scripted scenarios) and generation is `edit-needs-key`; on the **hosted** build with no key the Agent pane shows `edit-agent-needs-key` and `edit-composer-send` is disabled. Map: [`docs/internal/maps/edit-timeline.md`](../../../../docs/internal/maps/edit-timeline.md).

Product: both · Instance: main :3000

## Sub-features

- `edit-shell` shows `edit-studio`, `edit-timeline`, `edit-preview`, `edit-agent-panel`, plus the header handles `edit-tier`, `edit-jobs`, `edit-export`, `edit-export-progress`, `edit-export-download` and the footer counter `edit-ops-count`. With **no** project open the list side is `edit-project-list` + `edit-starter` + `edit-starter-description` + `edit-project-name` + `edit-new-project`, `edit-export` is disabled, and `edit-composer`, `edit-composer-send`, `edit-import`, `edit-generate-tab` and `edit-ops-count` have count **0**. That empty state is `EditEmptyState` (`apps/web/components/edit-empty-state.tsx`), one, two or three columns by the pane's width (see the **Empty-state layouts** step below). The header art column (`buddy-stage-header`, `buddy-stage-header-tap`) is in the DOM at every width but only visible when the header is 60rem or wider.
- `edit-transport` `edit-play`, `edit-time`, `edit-playhead`, `edit-zoom`, tracks `edit-track-<id>`; a pending (generating) clip renders as `edit-placeholder`, not `edit-clip` (`apps/web/components/edit-timeline.tsx:228`). The preview layers are `edit-preview-image`, `edit-preview-video`, `edit-title-overlay`, `edit-caption-overlay`.
- `edit-ffmpeg-setup` when ffmpeg is missing: `edit-needs-ffmpeg` carries `ffmpeg-install-command` and `ffmpeg-recheck` (re-probes `GET /api/v1/edit/doctor?recheck=1`, throttled to one forced probe per 2 s — `RECHECK_MIN_INTERVAL_MS`, `packages/host/src/edit/doctor.ts:55`, applied at `:64`; on the hosted server the report carries no `ffmpeg.path` and no `ffmpeg.setup` (the server's platform, install command and env var name), `withoutBinaryPath` at `:42`; `found`, `version` and `reason` stay). `ffmpeg-setup-steps` only renders in the onboarding `variant="full"`. On the **hosted** build `edit-needs-ffmpeg` is one calm line (`edit.ffmpeg.hostedUnavailable`) with no `ffmpeg-install-command`, no `ffmpeg-recheck`, no Copy and no link, because a tenant cannot install anything on the server; the onboarding key step does not show the guide there at all.
- `edit-ffmpeg-bundled` **the retired desktop app carried its own ffmpeg** (`resources/ffmpeg/`, staged by `apps/desktop/scripts/stage-ffmpeg.mjs`; `resolveFfmpeg` reads it before PATH, only `AGENTFORGE_FFMPEG_PATH` outranks it, `packages/host/src/edit/ffmpeg-binary.ts` `packagedBinary`). Meeting's `meeting-no-ffmpeg` says the same (`meeting.noFfmpegBundled`, from capability `ffmpegBundled`), the Meeting upload refusal says "Reinstall the app, or paste the transcript instead", and the Edit agent's prompt line tells the model to say "reinstall" and names no command. Webdev is never packaged (`AGENTFORGE_PACKAGED` unset), so none of this shows there: the install guide above is what webdev drives. Not driven: no installer has been packed with the bundle yet; unit coverage is `packages/host/src/edit/ffmpeg-binary-bundled.test.ts`, `apps/web/lib/ffmpeg-bundled-notice.test.tsx` and `apps/desktop/scripts/stage-ffmpeg.test.mjs`.
- `edit-agent-needs-key` (hosted only) the shared `NeedsKeyNote` above `edit-composer`, with its link `edit-agent-needs-key-settings` to `/settings`; while it shows, `edit-composer-send` is `disabled` (`apps/web/components/edit-agent-panel.tsx:112-118`, `:132`; the note carries the id `edit-agent-needs-key-note`). While it shows, the other doors to the agent are quiet as well: `edit-plan-go` on a plan card and every `edit-recipe-<id>` are `disabled` with a `title` ("Add your key in Settings to use this.", Indonesian on an `id` desk) and `aria-describedby="edit-agent-needs-key-note"`, and the Generate tab's `edit-generate-submit` (already disabled for a missing key) gains the same `title` and an `aria-describedby` at its own note `edit-needs-key` (id `edit-generate-needs-key-note`), with `edit-generate-prompt` described by it but still editable. These three are proven by unit tests only, **not yet driven in a browser**.
- `edit-import` adds a clip from a file (webdev multipart; packaged `pickMedia`).
- `edit-import` **refuses a playlist or a script** (SR-135, `packages/host/src/edit/ffmpeg/input-safety.ts`). After the probe, a container named `hls`, `applehttp`, `concat`, `sdp`, `rtsp`, `rtp`, `ffmetadata`, `data` or `dash` is a `400 unsupported_media` whose message is `mediaFormatRefused` ("This file is a playlist or a list of other files, not a video or audio recording, so it was not opened"; Indonesian on an `id` desk), not the generic "could not read" line, and the saved file is unlinked and the storage charge refunded as for any failed import. The upload is stored as `<id>.<mime subtype>`, so ffmpeg never sees the picked file's own name; content decides. A text file named `list.mp4` that holds `ffconcat version 1.0` and `file ok.mp4` (or `;FFMETADATA1`) is detected as `concat` / `ffmetadata` and refused; an HLS playlist is only detected by an `.m3u8` name, so it fails as "could not read" through this door. Every ffmpeg and ffprobe run also gets `-protocol_whitelist file,crypto,data` (`run.ts`), so nothing here opens an address. Hosted runs have timeout caps (an hour for analysis, two for a render). Proven by `ffmpeg-input-safety-real.test.ts` against the staged 8.1.3 programs; **not driven in a browser**.
- `edit-cut` split / trim / move / delete with undo (`edit-ops-count`).
- `edit-cards` Keep / Undo / Tweak; pending cards cancel on Undo. The panel also carries `edit-spend-meter`, the gate card `edit-review-card`, `edit-plan-go`, `edit-card-progress`, `edit-card-cancel`, and the unplaced tray `edit-tray` with `edit-tray-item` (`edit-tray-place` / `edit-tray-discard`).
- `edit-review-gate` `edit-export` disabled until scrub or `edit-review-ok`.
- `edit-titles` ASS-subset title + `edit-parity-check`.
- `edit-generate` Generate tab (image / video), `edit-tray`, per-item `edit-recipe-<id>` (the recipes panel has no wrapping testid), `edit-starter`. The Storyboard sub-tab is a placeholder in this build — `Storyboard lands in Phase 3.` The form is `edit-generate` itself, with the sub-tab buttons `edit-generate-image` / `edit-generate-video` / `edit-generate-storyboard` and the fields `edit-generate-tier`, `edit-estimate`, `edit-generate-model`, `edit-generate-seconds`, `edit-generate-still-clip`, `edit-generate-still`, `edit-generate-prompt`, `edit-generate-submit`.
- `edit-keep-scenarios` S1–S10 and Fill F1–F5 results tables (owner runs).
- `edit-prompt-templates` Generate tab › Video: cited, model-agnostic prompt templates (BytePlus Seedance guides + Higgsfield blog) embedded offline. Category bar `edit-prompt-template-categories` (with `edit-prompt-template-category-all`) and filters `edit-prompt-template-category-<id>`, list `edit-prompt-template-list` with items `edit-prompt-template-<id>`, citation `edit-prompt-template-source`, rules `edit-prompt-guide`. The heading, All, empty line, category labels, titles, citation prefix and prompting rules read `edit.templates.*` (`Mulai dari templat prompt`, `Semua`, `Aturan prompt` on an `id` desk). The filled prompt, tips and source note stay the cited English. Picking fills the prompt + seconds; the model select is untouched.
- `edit-starter-media` starters with bundled sample media (`promo-16x9`, `talk-16x9`, `reels-9x16`, `square-1x1`): clips land on `v1` / `a1` at create time from `apps/desktop/resources/starters/` (packaged: `resources/starters`). Offline only; a missing file is skipped and logged, never fetched. `edit-starter-description` shows the one-liner under `edit-starter`.
- `edit-harness` is the composer, not a new button. Five sentences run a skill instead of the free tool list: "Lift the dead air", "Cut where the picture changes", "Put words on the picture: …", "Make a still of …" / "Make a clip of …", and "Hand me the file" (or `export`). S1–S11, F1–F5, and sentences that start with `generate image` or `generate video` stay on the scripted path.

## Gotchas

- **The export file route honours `Range` (2026-10-14, not driven).** `GET /api/v1/edit/projects/:id/export/:jobId/file` answers 200 for the whole render, 206 with `Content-Range` for a range and 416 past the end, and takes the mime and the `export.<ext>` name from the file the job wrote (`rangedFileResult`, `packages/host/src/file-bytes.ts`). A plain browser download sends no `Range`, so a 200 is the normal answer; to check seeking, send `Range: bytes=0-99` and expect 206. The download name now also reads an RFC 5987 `filename*` (`filenameFromDisposition`, `apps/web/lib/download-name.ts`). Unit proof: `packages/host/src/edit/export-file-route.test.ts`.

- Stub agent replies are scripted per prompt; a live reply needs the operator's key on Windows only. "Add a title card that says Hello" is the stub title path (`S11`): it calls `add_title`, which lands an `add_clip` op, so the card reads `add clip · <clipId>` and the timeline clip is labelled with the clip id prefix while Hello is drawn in `edit-preview`. S6 "Summer Sale" is unchanged.
- A live turn binds every edit tool and sends the refreshed chat model. The literal model id `edit` is not a gateway model, and an empty binding list leaves the timeline empty because the runtime never calls `add_title`.
- ASR unavailable is a note, not a fail.
- **A Windows export once failed on every timeline with a clip: ffmpeg said "Unable to parse original_size" and the job only said `ffmpeg recipe failed`.** `escapeFilterPath` (`packages/host/src/edit/ffmpeg/paths.ts:86`) escaped the drive colon one level, but ffmpeg unescapes a `-filter_complex` string twice, so `C\:/...` split into a file name `C` and a stray option. It now escapes two levels (`C\\:/...`), proven by a real render in `ffmpeg-input-safety-real.test.ts` (libx264, read back with ffprobe). A path with no colon never showed it, so webdev on macOS or Linux and the hosted image could not have caught it. If an export on Windows fails again with that text, this regressed. Not yet driven in the packaged app.
- The recipes panel has **no** wrapping testid. Assert a per-item `edit-recipe-<id>` (e.g. `edit-recipe-podcast-clean-up`); `edit-recipes` does not exist.
- Storyboard is Phase 3 work. The sub-tab **button** is `edit-generate-storyboard` (`apps/web/components/edit-generate-tab.tsx:196`) and it does exist; what it opens is the literal copy `Storyboard lands in Phase 3.` with no `edit-generate-prompt`, no `edit-generate-submit` and no `edit-generate-tier`. F1 and F2 stay not drivable, and `animate_storyboard` lives only in the host agent tools. Neither `edit-storyboard-generate` nor `edit-storyboard-animate-all` exists — do not invent them.
- **The project event stream echoes your own ops back, and the studio now takes the second copy as a no-op.** `appendOps` emits `ops.appended` for every append including yours (`packages/host/src/edit/ops.ts:356`); import's response, the agent turn's `edit.ops` frame and `commitOps`'s response carry the same ops again.
